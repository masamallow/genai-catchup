#### [A] Meta AI Research — Introducing Muse Spark Open, The Most Capable US Open-Weight Model to Date (2026-10-15)

<https://research.meta.ai/blog/muse-spark-open>

- Meta released the weights on October 15 for a natively multimodal model of 816B total and 42B active parameters with a 1M-token context, built for coding and agentic work.
- Meta calls it the most capable US open-weight model to date, strong at long-horizon tasks, complex software engineering and multi-step reasoning.
- Hosted APIs at launch are Baseten, Fireworks AI, Groq, Modal, Nebius, OpenRouter and Together AI.
- The weights download from Hugging Face, Amazon SageMaker AI, Google Cloud Model Garden and Microsoft Foundry Models.
- It runs on SGLang, vLLM, TensorRT-LLM, Hugging Face Transformers, Apple MLX, llama.cpp and Unsloth, with optimisations for AMD, Apple, Intel and NVIDIA silicon.
- Meta says it is the first model in its class to run on a desktop: two M5 Ultra Mac Studios with up to 512GB of unified memory and 1.2 TB/s of bandwidth each, on the latest MLX.
- Meta's on-device tests ran Muse Code on the model to ship bug fixes and features to the Ice Cubes iOS app and to drive DaVinci Resolve end to end.
- It ships auto-tunable Helion GPU kernels in SGLang, with 1.03–3.95× kernel-level speedups on NVIDIA and AMD GPUs and a 3% end-to-end speedup on AMD MI350.
- The open version received extra safety post-training and met the release thresholds of the Meta Superintelligence Scaling Framework, with a full evaluation report announced as coming soon.
- Meta says the Muse Model License has "limited commercial terms, which allow many developers to use the model for free".

- AA frames the price two ways: its thread calls the cost per task moderate, while [its model page](https://artificialanalysis.ai/models/muse-spark-open) calls it particularly expensive per token against open models of its size (medians $0.43 and $1.68).
    - The same page measures 130.7 tok/s and 0.73 s to the first token as the median across providers.
- The lineage is unclear.
    - Jack Rae calls it the first base model MSL trained, with careful extra training for the open release; gihyo says it shares its base model with Spark 1.3, which no Meta page read says; AA measures it at Spark 1.2's level; vLLM says Muse Glimmer 30B was distilled from it.
    - Background: on August 10, alongside Muse Glimmer (30B dense, Apache 2.0), Alexandr Wang promised an open-weight version of Muse Spark 1.2 "soon" ([AINews, 2026-08-11](https://www.latent.space/p/ainews-muse-glimmer-and-spark-open)).
    - An HN commenter calls the 10-15 release a bait and switch, while AINews says it fulfils the promise with a model weaker than Spark 1.3; the licence also moved from Glimmer's Apache 2.0 to a custom one.
- The footprint figures disagree.
    - BF16 is about 1.6TB per Meta's developer page and AA, about 1.5TB per the Hugging Face blog, and more than 1.6TB per Apple.
    - NVFP4 is about 530GB, "about a third the size of BF16", per Meta's developer page, about 493GB per Apple, and "roughly a quarter of the memory" of BF16 per both the [AWS What's New post](https://aws.amazon.com/about-aws/whats-new/2026/01/muse-spark-open-on-sagemaker-jumpstart/) and the AWS blog.
    - The model card's minimum of 700GB of GPU memory for NVFP4 and 2TB for BF16 presumably covers cache and activations as well.
    - AWS sizes NVFP4 for `ml.p5e.48xlarge` and BF16 for `ml.p6-b300.48xlarge`, in US East (N. Virginia) and US East (Ohio) at launch, with JumpStart IDs `meta-vlm-muse-spark-open-816b-a42b` and `meta-vlm-muse-spark-open-816b-a42b-nvfp4`.
- The KV cache at 1M tokens is disputed.
    - The Hugging Face blog counts 126,976 values per token over all 62 layers, about 266GB at 1M tokens in BF16, an HN commenter cites "over 200GB", and Teortaxes calls the attention obsolete.
    - vLLM says 46 of the 62 layers keep only a 2,048-token window, which brings the cache to just over a quarter of all-full attention; the Hugging Face figure looks like an upper bound to check by measurement.
    - Elie Bakouch notes that the major US open models other than NVIDIA's Mamba hybrids use sliding windows too, Muse's 3:1 ratio and 2K window being the more conservative, and that Muse alone has no shared experts.
- The hosted terms are launch terms.
    - Fireworks serves it as a limited preview through October 29 on US-only capacity with its usual 50% US-only premium waived; Together lists a free endpoint "for limited time", which AINews dates to October 18.
    - Groq lists it as a preview with a 131,072-token context and output limit and text and image input only; OpenRouter routes to five providers (Modal, Together, Nebius Token Factory, Fireworks, Baseten), allows 262,144 completion tokens and is not available through EU in-region routing.

    - vLLM ships prebuilt images (`vllm/vllm-openai:muse-spark-open`, `vllm/vllm-openai-rocm:muse-spark-open`), but nightly wheels wait on PR #61879, which it expects to take about a week.

### Collected information

#### [A] Air Security — Plugin4Shell - Zero Click RCE Vulnerability found in top 4 most popular coding agents, millions of agents affected, by Or Nevo, Dor Granat and Niv Hoffman (2026-09-17)

<https://www.air.security/blog-posts/plugin4shell>

- Each of the four agents checks out the commit a marketplace pinned but never verifies that HEAD landed there, so different code installs while the agent reports the pinned SHA.
- Claude Code, Codex and Copilot run `git clone` and `git checkout <40-hex sha>`, and git resolves a name that is both a ref and an object ID to the ref, warning only `refname is ambiguous`.
- The attacker makes a branch named after the pinned SHA the repository's default, so the clone creates it locally; a non-default branch arrives only as a remote-tracking ref and the commit wins.
- GitHub rejects 40-hex branch names, but Bitbucket and self-hosted git servers accept them, and Anthropic's docs list both as supported marketplace hosts.
- Gemini CLI runs `git clone --depth 1`, `git fetch origin <sha>` and `git checkout FETCH_HEAD`, and a default branch named `FETCH_HEAD` captures the checkout, discarding the fetched commit.
- Zero-click, per AIR: once the marketplace re-pins a plugin to a new benign commit, the attacker points a default branch of that name at malicious code, and auto-update installs it unprompted.
- AIR says auto-update is the default in Claude Code and Codex, and that the attacker needs only the plugin's repository, by publishing a benign plugin or taking over a trusted one.
- The fix is one assertion inside the agent, `test "$(git rev-parse HEAD)" = "<pinned-sha>" || abort`, which checks the resolved HEAD rather than the requested ref; no marketplace can enforce it.
- AIR found the flaw in May 2026 with a PoC against all four agents and disclosed it in June; Anthropic confirmed the 2.1.179 fix on 06-17 and Codex 0.146.0 was verified fixed on 08-12.
- Microsoft has shipped no Copilot fix, and Google said on 08-04 that it will not patch the deprecated Gemini CLI, pointing users to Antigravity, which has no plugin SHA pinning to bypass.

#### [A] Claude Platform Docs — OpenTelemetry for the Claude API, Set up OpenTelemetry with the Claude API, Set up OpenTelemetry with the Claude SDK and OpenTelemetry span reference (as fetched on 2026-10-17)

<https://platform.claude.com/docs/en/manage-claude/opentelemetry> / <https://platform.claude.com/docs/en/manage-claude/opentelemetry/api> / <https://platform.claude.com/docs/en/manage-claude/opentelemetry/sdk> / <https://platform.claude.com/docs/en/api/opentelemetry/spans>

- SDK spans (code, no permission) cover the SDK's requests and the tools the app runs, while API spans (Console, admin, any client) add each model run, Managed Agents turns and server tools.
- SDK tracing is in beta on the Claude API, Claude Platform on AWS, Amazon Bedrock, Google Cloud and Microsoft Foundry, but API tracing only on the Claude API and Claude Platform on AWS.
- A destination needs the admin role, an OTLP/HTTP endpoint taking protobuf over HTTPS on port 443 and credentials in headers, and its Test action sends an `anthropic.test` span.
- Destinations can also be created with `POST /v1/organizations/telemetry_destinations` (beta header `telemetry-destinations-2026-08-11`) or `ant beta:organization:telemetry-destinations create`.
- Delivery is at least once and best effort with a 10 s timeout, an organization gets 10 destinations, and the API disables a destination after a 3xx, a non-public IP or 24 h of failed deliveries.
- Attributes follow the GenAI conventions at commit `e57c543b` of 2026-09-24, on spans such as `anthropic.messages.create`, `anthropic.model_request`, `anthropic.session.turn` and `anthropic.tool_use <tool>`.
- API spans nest under the app's spans through the W3C `traceparent` header, are not emitted when its sampled flag is off, and the MCP connector passes the context on to MCP servers in `params._meta`.
- Metadata only (`metadata_only`, default) exports IDs, timing, status, token counts and agent and tool names, and Full content (`content`) adds prompts and responses, 0.75 MB per span by default.
- HIPAA, FERPA or K-12 restrictions limit destinations to metadata (SDK spans unaffected), and under ZDR the API holds Messages API content in memory until delivery, Managed Agents excluded.
- The beta falls under the Beta Services terms, the SDK page warns options and span schema may break (pin the SDK), and the guide says spans are no complete usage record, unlike the Usage API.
