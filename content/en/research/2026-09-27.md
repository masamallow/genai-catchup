#### [A] TypeSafe AI — Introducing System One Models & Jev (2026-09-15)

<https://typesafe.ai/blog/introducing-system-one-models-and-jev>

- System One models are "a new class of frontier models built to make fast, structured decisions that software can use directly".
- Jev follows the pattern "unstructured state in, typed probabilistic decisions out", and it samples in parallel, generating "all outputs in a single query" instead of one token at a time.
- Because the "possible outputs and structure are defined in advance", the model "can't hallucinate" and "never makes type errors" by construction.
- Training uses RLCD (Reinforcement Learning for Calibrated Decisions) instead of RLHF / RLVR, aiming for calibration where "higher confidence means higher accuracy".
- On System One tasks Jev is "40x-200x faster" than frontier LLMs, answering end to end in "70ms-500ms" against "3 to 329 seconds" for frontier models.
- Input costs "$0.042 / MTok" and output is free, "too cheap to meter", while frontier models charge "from $0.20 to $10 / MTok" for input.
- Early access brings developers "off the waitlist" step by step, and Jev is used from console.typesafe.ai.
- Because Jev "gives up string generation", it cannot produce free-form text such as chat replies or generated code.

#### [B] LangChain — What Is Jev? A Guide to TypeSafe AI's System One Model (2026-09-17)

<https://www.langchain.com/blog/building-a-harness-with-jev>
