# 1️⃣ 🌍 GPT-6.1 Terra: computer use and vision at $1/$5 per 1M, half of Sol's rates

<p class="lede">Released by OpenAI on 10-26 as the successor to GPT-5.6 Terra, in the API, ChatGPT Work and Codex, and the same day on Amazon Bedrock and in GitHub Copilot.</p>

<div class="cols">
<div>

## Key points

- `gpt-6.1-terra`: $1 input, $0.05 cached and $5 output per 1M, half of GPT-6.1 Sol; GPT-5.6 Terra cost $2, $0.20 and $12.
- OpenAI: Agents' Last Exam at medium effort, 15 points over GPT-5.6 Terra at a third of the cost, level with GPT-6 Astra.
- Terminal-Bench 4.0 at max effort: 50.3% to GPT-5.6 Terra's 21.5%, yet OpenAI keeps Sol and Astra for the hardest coding.
- Artificial Analysis (AA), max effort: index 48 (Sol 52, GPT-5.6 Terra 42) at $0.40 a task, against $1.40 for GPT-5.6 Terra.
- Errors on OpenAI's own set: 53.6% to 16.7% at low effort; AA-Omniscience: guesses on 38% of unknowns (GPT-5.6 Terra 88%).

## Perspectives and debates

- The Decoder pits it against Claude Sonnet 5.5 at half its $2/$10; an OpenAI employee on HN places it between Luna and Sol.
- Only low and medium effort sit on AA's cost frontier, yet OpenAI's Opus 5.5 and Terminal-Bench claims use max effort.
- AA's max runs: 90.9 tok/s to Sol's 69.4, but 130M output tokens to 67M; its Terminal-Bench gain is ~20 points, not 28.8.

</div>
<div>

## Technical details

- Bedrock `openai.gpt-6.1-terra`, EOL not before 2027-10-26: 1,050,000-token context, 128,000 output, text and images.
- Cross-Region profiles only: `us.openai.gpt-6.1-terra` (US, Canada) or `global.`, the sole option in Tokyo and Osaka.
- Global rates match OpenAI's, cache write $1.25; past 272K input: $2, $2.50, $0.10, $7.50; In-Region and Geo add 10%.
- Standard tier only; Converse rejects documents and tool-result images, so documents go through Responses as `input_file`.
- Classmethod (in Japanese): Converse from Tokyo in 959 ms; SigV4 to `/openai/v1` in us-east-1 needs only a model ID swap.
- Copilot Pro, Pro+, Max, Business, Enterprise: usage-billed at list price, on by default unless an admin turned it off.

</div>

# 2️⃣ 🧩 Anthropic: fold most subagents into one agent loop with on-demand skills

<p class="lede">Published by Anthropic on 10-22, before the window, with single-agent-loop-kit, an unmaintained Apache-2.0 reference implementation on GitHub.</p>

<div class="cols">
<div>

## Key points

- Applied AI's enterprise comparisons: "a single agent with skills frequently outperformed" one-prompt and subagent designs.
- One customer comparing its multi-agent harness with a single loop saw a roughly 2x faster runtime.
- Skills hold procedures, intent-grouped tools hold limits and permission checks; tool choice degrades past 30–50 tools.
- Subagents stay for measurable context bloat, parallel work in fresh contexts, failing tool choice or conflicting rules.
- Migration starts from a 10-example eval; in a sample agent, a fold cut latency but broke a passing task in one of two runs.

## Perspectives and debates

- Anthropic: team-by-team agents copy the org chart (Conway's law); a central team owns prompt and eval, DRIs own skills.
- Qiita (in Japanese): one loop took 6.30 s and $0.0093 a task against 13.49 s and $0.0241 for five subagents, quality level.
- Evidence: one unnamed customer and two real-model kit runs; a Hatena commenter calls a fold that drops a check a step back.

</div>
<div>

## Technical details

- Kit skill (`.claude/skills/single-agent-loop`): fold, merge, call as a tool or keep per subagent; asks before paid runs.
- `reference_loop/loop.py`: `tool_search_tool_bm25_20251119`, `load_skill`, write gates; 25 turns, 400k tokens, 16 calls a batch.
- `examples/support-desk`: a router over six subagents, 19 tasks and 200 synthetic traces, run offline with `KIT_MODEL=fake`.
- Tool search: `defer_loading: true` keeps up to 10,000 tools out of the prefix; a search returns up to 5 by default.
- Five MCP servers' ~55k tokens of definitions typically shrink by 85%+; a deferred tool with `cache_control` returns a 400.
- Classmethod (in Japanese): approval gates became `ask` rules for `gh pr create` and `git push`; six reviewers became two.

</div>
</div>

# 3️⃣ ✂️ Claude finds needless attack surface: 493 issues in 25 projects, OpenSSH fixes

<p class="lede">Published by Anthropic's Frontier Red Team on 10-20, before the window, after OpenSSH 10.5 shipped a fix credited to its author, Chris Rohlf, and 10.6 fixes credited to him with Claude.</p>

<div class="cols">
<div>

## Key points

- Three checks: unused but reachable default code, option pairs that silently disable a control, sensitive pre-auth code.
- 25 projects, 5M+ lines in C, C++, Java, PHP, Python and more: 17,000+ options, 3,842 security-relevant, 493 issues found.
- All 11 Gated-group projects exposed needless code, with 93 default pre-auth surfaces; none was directly exploitable alone.
- 162 option pairs pass silently: 94 disable a control, 68 leave one inconsistent; one waived client certs for 21 years.
- A hostname-based deny rule failed open in four unrelated projects whenever reverse DNS lookups were off.

## Perspectives and debates

- Rohlf: gating code a deployment need not expose lowers the severity of its unknown bugs without finding any of them.
- TNW: results are Anthropic's own; HN users say Claude's cyber safeguards refuse defensive audits and proofs of concept.
- Unstated: whether the fifth was measured with ML-DSA off; 10.6 enables `ssh-mldsa44-ed25519`, so sshd parses it pre-auth.

</div>
<div>

## Technical details

- OpenSSH 10.4: ~4,500 lines of experimental ML-DSA-44 code were reachable before auth, even with the algorithm excluded.
- 10.5 (08-11) checks the key type before parsing; Claude found gaps in the inner key type and the CA signature path.
- 10.6 (10-06) checks allow lists inside the parser, cutting about a fifth of default pre-auth code, Anthropic says.
- The unreleased skill: three passes from empty contexts with short hand-offs; findings confirmed by dynamic trace.
- Patch gate: identical test and black-box results in default configs; changes to non-default setups go to a human.
- OSS-Scanner, the planned home: 185 projects enrolled by PR, audited offline by Claude Code; no attack-surface pass yet.

</div>
