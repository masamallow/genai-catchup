# 1️⃣ 🌍 GPT-6.1 Terra: コンピューター操作と視覚向け、100 万トークン $1/$5 で Sol の半額

<p class="lede">OpenAI が 10-26 に GPT-5.6 Terra の後継として API、ChatGPT Work、Codex で公開し、同じ日に Amazon Bedrock と GitHub Copilot にも載った。</p>

<div class="cols">
<div>

## 要点

- `gpt-6.1-terra`: 100 万トークンあたり入力 $1 (キャッシュ $0.05)、出力 $5 で GPT-6.1 Sol の半額、GPT-5.6 Terra は $2、$0.20、$12。
- OpenAI によれば Agents' Last Exam は推論 medium で GPT-5.6 Terra を 15 ポイント上回ってコストは約 3 分の 1、GPT-6 Astra と並ぶ。
- Terminal-Bench 4.0 は max で 50.3% (GPT-5.6 Terra は 21.5%) だが、OpenAI は最も複雑なコーディングには Sol と Astra を勧める。
- Artificial Analysis (AA) の指数は max で 48 (Sol 52、GPT-5.6 Terra 42)、タスクあたり $0.40 で GPT-5.6 Terra は $1.40。
- 誤り率は OpenAI 自身のセットの low で 53.6% → 16.7%、AA-Omniscience で答えられない問いへの当て推量は 88% → 38%。

## 見方と論点

- The Decoder は Claude Sonnet 5.5 ($2/$10) への半額の対抗馬と位置づけ、HN では OpenAI の社員が Luna と Sol の間に置く。
- AA がコスト面でパレート最適とするのは low と medium だけだが、OpenAI の Opus 5.5 との比較と Terminal-Bench の数値は max のもの。
- AA の max の計測では毎秒 90.9 トークンと Sol の 69.4 より速いが出力は 130M 対 67M、Terminal-Bench の伸びは 28.8 でなく約 20。

</div>
<div>

## 技術要素

- Bedrock の `openai.gpt-6.1-terra` は提供終了が早くても 2027-10-26、コンテキスト 1,050,000、出力 128,000、入力はテキストと画像。
- 呼べるのはクロスリージョンのプロファイルだけで、`us.openai.gpt-6.1-terra` (米国、カナダ) と、東京と大阪で唯一の `global.`。
- Global は OpenAI と同額でキャッシュ書き込み $1.25、入力 272K 超は $2、$2.50、$0.10、$7.50、In-Region と Geo は 10% 高い。
- 階層は Standard のみ、Converse はドキュメントとツール結果の画像を受け付けず、ドキュメントは Responses の `input_file` で渡す。
- クラスメソッド: 東京から Converse で 959 ms、us-east-1 の `/openai/v1` も SigV4 署名で通り、Sol からはモデル ID の切り替えだけ。
- Copilot は Pro、Pro+、Max、Business、Enterprise で、利用量課金は定価、管理者が無効にしない限り既定で有効。

</div>
</div>

# 2️⃣ 🧩 Anthropic: サブエージェントの多くは、スキルを都度読み込む単一ループに畳む

<p class="lede">Anthropic が期間前の 10-22 に記事を公開し、保守しない Apache-2.0 の参照実装 single-agent-loop-kit も GitHub に置いた。</p>

<div class="cols">
<div>

## 要点

- Applied AI による企業導入の比較では、スキルを持つ単一エージェントが品質で 1 プロンプトやサブエージェントの設計をしばしば上回った。
- 複数エージェントのハーネスを単一ループと比べたある顧客では、実行時間が約 2 倍速くなった。
- 手順はスキルに、厳格な制限と権限チェックは利用者の意図ごとにまとめたツールに持たせ、30〜50 ツールを超えると選択が劣化する。
- サブエージェントを残すのは、計測できるコンテキストの肥大、新しいコンテキストでの並列作業、ツール選択の失敗、指示の衝突のとき。
- 移行はゴールデン例 10 件の評価から始め、サンプルのエージェントでは畳むと速くなったが、通っていたタスクが 2 回に 1 回壊れた。

## 見方と論点

- Anthropic はチームごとのエージェントが組織図を写す (コンウェイの法則) とし、プロンプトと評価は中央チーム、スキルは各 DRI が受け持つ。
- Qiita の計測では単一ループが 1 タスク 6.30 秒、$0.0093 で、5 体のサブエージェント構成は 13.49 秒、$0.0241、品質は互角。
- 根拠は名前のない 1 社と、キットを実モデルで回した 2 回だけで、はてなには「統合で速くなっても、必要な確認が抜ければ後退だ」との声。

</div>
<div>

## 技術要素

- キットの `.claude/skills/single-agent-loop` は各サブエージェントに畳む、統合、ツール化、残すの判定を出し、有料の実行前に確認する。
- `reference_loop/loop.py`: `tool_search_tool_bm25_20251119`、`load_skill`、書き込みゲート、25 ターン、40 万トークン、1 バッチ 16 件。
- `examples/support-desk` はルーターと 6 つのサブエージェント、19 タスク、合成トレース 200 件で、`KIT_MODEL=fake` でオフラインで動く。
- tool search は `defer_loading: true` のツールを最大 10,000 までプロンプトの先頭から外し、検索は既定で最大 5 件を返す。
- 5 つの MCP サーバーの約 55k トークンの定義は通常 85% 超減り、遅延したツールに `cache_control` を付けると 400 が返る。
- クラスメソッドは承認ゲートを `gh pr create` や `git push` の `ask` ルールに移し、実装後のレビュー役を 6 体から 2 体にした。

</div>
</div>

# 3️⃣ ✂️ Claude が不要な攻撃対象領域を探す: 25 の OSS で 493 件、OpenSSH は修正済み

<p class="lede">Anthropic の Frontier Red Team が期間前の 10-20 に公開し、著者 Chris Rohlf による OpenSSH の修正は 10.5 と、Claude の名も挙げた 10.6 で出ていた。</p>

<div class="cols">
<div>

## 要点

- 3 つの手法が探すのは、既定で届くのに既定の機能が使わないコード、黙って制御を外す設定の組、認証前に動く機微なコード。
- C、C++、Java、PHP、Python など 500 万行超の 25 プロジェクトで、設定 17,000 超から 3,842 をセキュリティ関連とし、493 件を発見。
- Gated 群の 11 プロジェクトすべてに不要に届くコードがあり、既定で認証前に触れる面は 93、ただし単独ですぐ悪用できるものはない。
- 警告なく通る設定の組 162 件のうち 94 件は制御を無効に、68 件は不整合にし、クライアント証明書の要求を 21 年間外していた組もある。
- ホスト名による拒否ルールは、逆引き DNS がオフだと無関係な 4 つのプロジェクトで素通しになった。

## 見方と論点

- Rohlf は、その環境で外に出す必要のないコードをゲートの後ろに置けば、未知のバグを 1 つも見つけずに深刻度を下げられると論じる。
- TNW は結果が Anthropic 自身のものだと注意し、HN では Claude のサイバーの安全策が防御の監査や PoC を拒むとの訴えが目立つ。
- 約 5 分の 1 を ML-DSA 無効で測ったかは不明で、10.6 は `ssh-mldsa44-ed25519` を既定で有効にし、sshd は認証前にその鍵をパースする。

</div>
<div>

## 技術要素

- OpenSSH 10.4 では実験的な ML-DSA-44 のコード約 4,500 行に、アルゴリズムを除外していても認証前に届いた。
- 10.5 (08-11) は鍵の型をパースの前に照合するが、Claude は内側の鍵の型と CA の署名の経路に抜けを見つけた。
- 10.6 (10-06) はパーサーの中で許可リストと照合し、Anthropic によれば既定の認証前のコードを約 5 分の 1 削った。
- 未公開のスキルは空のコンテキストと短い引き継ぎから 3 つのパスを回し、所見は動的なトレースで確かめる。
- パッチの条件は既定の設定でテストとブラックボックスの結果が変わらないことで、既定以外の構成に響くものは人に回す。
- 組み込み先の OSS-Scanner は PR で登録した 185 件を Claude Code でオフライン監査するが、攻撃対象領域のパスはまだない。

</div>
</div>
